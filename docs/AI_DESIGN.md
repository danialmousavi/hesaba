# طراحی دستیار هوشمند

این سند طراحی پیشنهادی است؛ اتصال Ollama، ابزارها، جریان تأیید و رابط AI هنوز پیاده‌سازی نشده‌اند.

## اجرا

Ollama به‌صورت محلی با مدل پیشنهادی `qwen3.5:4b` اجرا می‌شود. اطلاعات مالی بدون مجوز به سرویس خارجی ارسال نمی‌شوند.

## جریان عملیات

```text
درخواست فارسی → استخراج ساخت‌یافته → اعتبارسنجی Zod → پیش‌نمایش → تأیید کاربر → سرویس دامنه → AuditLog
```

## مجوزها

- ابزارهای خواندنی فقط داده‌های مجاز همان سازمان را بازمی‌گردانند.
- ابزارهای نوشتنی مستقیماً اجرا نمی‌شوند و فقط یک پیش‌نویس معتبر تولید می‌کنند.
- اعتبارسنجی حسابداری، دسترسی و دورهٔ مالی مستقل از خروجی مدل است.

## سناریوهای MVP

خلاصهٔ مالی، جست‌وجوی گزارش، ساخت پیش‌نویس درآمد/هزینه، و ساخت پیش‌نویس فاکتور.
