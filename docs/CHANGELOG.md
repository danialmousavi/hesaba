- اجرای برنامه روی سیستم محلی و PostgreSQL نمونه روی Docker با پورت میزبان ۵۴۳۳ مستند شد.
- داشبورد راست‌چین، سایدبار، فونت‌های محلی، خلاصه مالی و نمودار ماهانه بر اساس داده واقعی افزوده شدند.
- مدل، API و رابط سال مالی، تقویم شمسی، کنترل هم‌پوشانی، رویدادها و بستن سال اضافه شدند.
- کدینگ درختی و ایجاد، ویرایش و تغییر وضعیت حساب‌ها اضافه شدند.
- اسناد دوطرفه، پیش‌نویس، ویرایش و حذف پیش‌نویس، ثبت نهایی، رویداد سند و محافظت دیتابیس برای اسناد نهایی اضافه شدند.
- گزارش‌های تراز آزمایشی، دفتر کل و سود و زیان با داده اسناد نهایی اضافه شدند.
- مدل، API و رابط ثبت، فهرست، جست‌وجو، ویرایش و تغییر وضعیت مشتریان و تأمین‌کنندگان اضافه شدند.
- مدل کالا و خدمات، قیود و migration آن اضافه شد؛ API و رابط آن هنوز موجود نیست.
- اسکریپت داده دمو برای سازمان مشخص و آزمون یکپارچه در دیتابیس موقت اضافه شد.
- مستندات اجرا، وضعیت واقعی معماری و فهرست کارهای آینده به‌روز شدند.

### Added

- مستندات اولیهٔ محصول، معماری، داده، AI و نقشهٔ راه.
- ثبت وضعیت TASK-001 و TASK-002.
- پیکربندی Docker برای PostgreSQL و ابزار Prisma.
- پیکربندی Prisma 7، Prisma Client و schema پایه.
- مدل‌های اولیهٔ سازمان، کاربر، عضویت و نقش‌ها همراه با migration پایدار.
- مدل‌های اصلی Better Auth شامل Session، Account و Verification همراه با migration پایدار.
- وابستگی‌های Better Auth، Prisma PostgreSQL adapter و pg افزوده شدند.
- Prisma Client مشترک و محدود به سمت سرور افزوده شد.
- سرویس Better Auth با ورود ایمیل/رمز عبور و Prisma adapter پیکربندی شد.
- Route Handler سازگار با App Router برای Better Auth افزوده شد.
- SDK سمت‌کلاینت Better Auth افزوده شد.
- صفحه و فرم ثبت‌نام فارسی با اتصال به Better Auth افزوده شد.
- فونت‌های محلی IRANYekanXFaNum و Modam در رابط کاربر اعمال شدند.
- مسیر نخست برنامه به صفحهٔ ثبت‌نام هدایت شد.
- صفحه و فرم ورود فارسی با اتصال به Better Auth افزوده شد.
- مسیر محافظت‌شدهٔ داشبورد و هدایت پس از ورود افزوده شد.
- خروج امن از حساب در داشبورد افزوده شد.
- جریان ایجاد سازمان اولیه و عضویت مدیر افزوده شد.
- نمایش پیام دقیق خطای Better Auth در فرم‌های ثبت‌نام و ورود بهبود یافت.
