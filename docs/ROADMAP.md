# نقشهٔ راه حسابا

این سند نمای کلی وضعیت پروژه است؛ جزئیات، وابستگی‌ها و معیار پذیرش کارهای باقی‌مانده در [TASKS.md](./TASKS.md) و جزئیات پیاده‌سازی در [ARCHITECTURE.md](./ARCHITECTURE.md) آمده است. ترتیب کارهای آینده پیشنهادی است و هر مرحله با دستور کاربر اجرا می‌شود. ابتدا بک‌اند هر قابلیت و سپس رابط آن ساخته می‌شود.

بسته‌بندی کارهای باقی‌مانده، تسک بعدی و ترتیب پیشنهادی در [برنامه اجرا](./EXECUTION_PLAN.md) آمده است.

## وضعیت تا اینجا

| حوزه | ساخته‌شده | باقی‌مانده |
|---|---|---|
| هویت و سازمان | ثبت‌نام، ورود، خروج، ایجاد سازمان، عضویت و نقش‌های پایه | انتخاب امن سازمان فعال و مدیریت اعضا و نقش‌ها؛ TASK-127 تا TASK-136 |
| سال مالی و حساب‌ها | سال مالی، تقویم شمسی، بستن سال، کدینگ درختی و API اختتامیه و انتقال مانده طبق [طرح](./FISCAL_YEAR_CLOSING_DESIGN.md) | رابط اختتامیه، اصلاح سال بسته و آزمون‌های تکمیلی |
| اسناد | پیش‌نویس، ویرایش، حذف و ثبت نهایی، رویدادها، محافظت سند نهایی و پیش‌نمایش و برگشت سند مستقل | فرایند اصلاح اسناد عملیات مرتبط و آزمون‌های تکمیلی |
| اشخاص | مدیریت اشخاص، حساب دریافتنی و پرداختنی، استفاده در فاکتور و پرداخت و گزارش گردش حساب و مانده فاکتورها | گزارش‌های تکمیلی مطالبات و بدهی‌ها و بهبود فیلترها |
| کالا و خدمات | مدل، API و رابط مدیریت کالا و خدمات و استفاده در فاکتور فروش | انبارداری پیشرفته خارج از MVP است |
| درآمد و هزینه | ساخت، فهرست و حذف پیش‌نویس و ثبت نهایی همراه سند | ویرایش پیش‌نویس و فهرست مستقل رویدادهای نهایی؛ TASK-123 تا TASK-126 |
| گزارش و داشبورد | تراز آزمایشی، دفتر کل، سود و زیان و خلاصه و نمودار ماهانه | فیلترها، خروجی‌ها و گزارش‌های وابسته به فاکتور، پرداخت و مانده اشخاص |
| فروش و دریافت/پرداخت | مدل، API و رابط فاکتور و صدور نسیه و ابطال بدون تخصیص، دریافت مشتری و پرداخت تأمین‌کننده | اصلاح دریافت، تخصیص پرداخت به فاکتور خرید و گزارش‌های مرتبط |
| دستیار هوشمند | طراحی پیشنهادی مستند شده است | اتصال Ollama، ابزارها، رابط و جریان تأیید؛ [AI_DESIGN.md](./AI_DESIGN.md) |
| کیفیت و ارائه | راهنمای اجرای محلی و بخشی از آزمون‌ها موجودند | آزمون یکپارچه و هم‌زمانی، بازبینی RTL و دسترس‌پذیری و سناریوی نهایی |

مدیریت پروفایل و تغییر رمز نیز در تسک‌های آینده ثبت شده‌اند. اتصال بانکی و درگاه واقعی، حقوق، سامانه مؤدیان، OCR، انبارداری پیشرفته، چندارزی پیشرفته و RAG خارج از MVP فعلی‌اند. وجود یک مدل یا صفحه به‌تنهایی به معنی تکمیل جریان کسب‌وکار یا آمادگی بهره‌برداری نهایی نیست.
